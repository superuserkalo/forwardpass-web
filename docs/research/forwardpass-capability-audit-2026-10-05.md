## Strongest real system differences from a basic scheduled research prompt

1. A maintained collection network rather than only query-time search: the static registry currently resolves to **765 configured streams** with 326 distinct publisher-ID strings. Of these, **33 require permission and 5 are references**, leaving 727 configured public routes, not 727 verified-healthy routes. The generated registry is 757 entries; source-streams adds eight established routes absent from it. Discovered sources join from a stored registry and can change deployed totals. Publisher IDs mix domain and short-name styles, so distinct IDs are not a reliable count of unique real publishers. [Registry composition](/Users/kalo/forwardpass/src/lib/source-streams.ts:45), [count implementation](/Users/kalo/forwardpass/src/lib/source-count.ts:11), [nonpublic routes skipped](/Users/kalo/forwardpass/src/lib/source-collector.ts:307).
2. Collection is scheduled every two hours; individual routes may run daily. Collection requires no model calls, shards the work into retryable steps, saves checkpoints and health, uses ETags/last-modified/seen IDs, recovers blocked routes through browser rendering twice daily, and adds source discovery. This makes comprehensive incremental monitoring an explicit system task rather than an implicit hope that a search finds enough. [Collection](/Users/kalo/forwardpass/src/collect/collect.ts:15), [shards](/Users/kalo/forwardpass/src/collect/collect.ts:61), [browser recovery](/Users/kalo/forwardpass/src/collect/collect.ts:96), [discovery](/Users/kalo/forwardpass/src/collect/collect.ts:141), [cron configuration](/Users/kalo/forwardpass/wrangler.jsonc:11).
3. Persistent observation history: snapshots include new candidates, trending artifacts, and attention measurements; previous snapshots inform attention collection. Candidate construction filters already-reported URLs over seven days, clusters related coverage, and merges duplicate release clusters. [History](/Users/kalo/forwardpass/src/collect/collect.ts:86), [deduplication](/Users/kalo/forwardpass/src/pipeline/candidates.ts:47), [freshness](/Users/kalo/forwardpass/src/pipeline/candidates.ts:114), [clustering](/Users/kalo/forwardpass/src/pipeline/candidates.ts:174). These are useful for quieter sources and ongoing change tracking; they do not establish superior recall without a benchmark.
4. Repeated source-grounding checks: selected feature stories capture source documents, extract facts with quotations, check quotation existence, rate facts, then run draft checks/grounding/repair. A failed full-page capture falls back to the lead title/summary, so "every story independently verified against full primary pages" would overstate it. Source evidence also does not prove a vendor's claim true. [Facts and fallback](/Users/kalo/forwardpass/src/pipeline/facts.ts:80), [draft pipeline](/Users/kalo/forwardpass/src/pipeline/issue.ts:82), [grounding/repair](/Users/kalo/forwardpass/src/pipeline/issue.ts:119).
5. An editorial learning loop exists, with limits: daily recall compares AlphaSignal coverage against stages in this pipeline, records misses, adjusts bounded publisher ranking weights, and sends missed sources into discovery. AlphaSignal items are excluded from the issue's candidate input. This is a specific recall feedback mechanism, not proof of human editorial taste or reader-personalized learning. [Benchmark separation](/Users/kalo/forwardpass/src/pipeline/candidates.ts:121), [learning](/Users/kalo/forwardpass/src/pipeline/recall.ts:135), [invocation](/Users/kalo/forwardpass/src/pipeline/issue.ts:179).
6. One published result is reusable across readers/channels/agents. Delivery implements recipient consent rechecks, idempotent retries and durable per-recipient outcomes. [Delivery](/Users/kalo/forwardpass/src/delivery/deliver.ts:10). This supports amortizing a maintained research operation across subscribers; no current unit-cost conclusion was measured.

## What should not be sold as an established advantage

- Personalized email generation is absent in this current path. Every reader receives the same saved IssueV2 rendered with their first name and account links. The website's For You ranking reorders existing stories by topic overlap. [Email](/Users/kalo/forwardpass/src/delivery/deliver.ts:92), [For You](/Users/kalo/forwardpass-web/src/lib/feed-rank.ts:17).
- Professional weekly research is advertised but its archive handler returns 404 even after authorization. Sunday editorial is a different general article. [Weekly branch](/Users/kalo/forwardpass/src/lib/archive.ts:76), [pricing claim](/Users/kalo/forwardpass-web/src/components/pricing-plans.tsx:41).
- MCP makes published editorial coverage conveniently reusable, but exposes neither the raw monitored corpus nor semantic search. It matches keywords in up to 31 editions per page, with pagination. It does not update continuously with source collection. [Query implementation](/Users/kalo/forwardpass/src/lib/agent-coverage.ts:82), [explicit daily scope](/Users/kalo/forwardpass/src/api/agent.ts:75).
- Signal corrections/retractions and 15-minute collection exist in code, but checked-in fast-lane and signal-publication flags are false. Do not promise a live correction service or faster-than-Cowork alerts based on code existence. [Flags](/Users/kalo/forwardpass/wrangler.jsonc:64), [correction implementation](/Users/kalo/forwardpass/src/lib/signals.ts:263).
- Upvotes exist; this audit found no evidence that they train editorial selection. The verified feedback loop is benchmark-driven.
- The website's 878-source fallback is not the above static count; the scanned-item number is a clock-based extrapolation of 2702 records per run times 12 runs/day, not a processing ledger. [Estimate](/Users/kalo/forwardpass-web/src/lib/source-stats.ts:1).
- No live healthy-source count, uptime/recall/factuality result, successful delivery rate, or Cowork-vs-Forward-Pass quality measurement was established here.

## Implication for the comparison

The strongest defensible current argument is a shared, continuously maintained AI-engineering monitoring and publishing operation: coverage definition, state, failure recovery, source evidence and repeat filtering are already packaged. A Cowork user can build analogous infrastructure, and a simple briefing may already meet their needs. The difference is the provided operated system, not an exclusive AI ability. Its value must be demonstrated through fewer important omissions, less repeated reading, dependable evidence and lower reader effort. A generic personalized-news pitch is weaker than this actual pipeline, and current paid gaps should be fixed before using personalization as its defense.
